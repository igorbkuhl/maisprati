# SQL - Structured Query Language

## Subdivisões dos comandos
### DDL - Data Definition Language
Define a estrutura para a base de dados.
Comandos:
- CREATE
- ALTER
- DROP
- TRUNCATE

### DML - Data Manipulation Language
Insere e altera dados.
Comandos:
- INSERT
- UPDATE
- DELETE

### DQL - Data Query Language
Faz consulta aos dados.
Comandos:
- SELECT

### DCL - Data Control Language
Faz o controle de permissões.
Comandos:
- GRANT
- REVOKE

### TCL - Transition Control Language
Controla as transações.
Comandos:
- COMMIT
- ROLLBACK
- SAVEPOINT

## Tipos de dados
- VARCHAR
- TEXT
- DATE
- INT
